# Crypto Intelligence Mobile v0.4.3

Полная комплектная версия на основе v0.4.2 с сохранением функций и исправленного Paper Trading v0.4.1.

## Добавлено
- Пикачу вынесен в отдельный `pikachu.css`.
- Стили имеют высокий `z-index`, `!important` для видимости и независимую анимацию.
- Пикачу пробегает по нижней части экрана и периодически машет лапой.
- При включённом системном режиме reduced motion он остаётся видимым справа без анимации.
- Service Worker cache обновлён до `ci-mobile-v043`, новый CSS добавлен в precache.

## Установка
Заменить **все файлы** в корне GitHub-репозитория содержимым этого архива. Архив содержит полный комплект приложения, а не только отдельный патч.
После успешного GitHub Pages deployment полностью закрой PWA и открой сайт в Chrome; при необходимости удали установленное PWA и установи заново.

## Проверка
Проверена структура ZIP и синтаксис JavaScript. Реальное отображение на конкретном телефоне требует проверки в браузере.
