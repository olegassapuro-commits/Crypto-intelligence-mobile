# Crypto Intelligence Lite Mobile v0.1.0

Мобильная версия для Android/iPhone. Нет собственного backend, VPS, Docker, AI или аккаунта биржи.

## Запуск и установка
PWA устанавливается через браузер, но для установки Service Worker требуется HTTPS или localhost. Самый простой путь:
1. Разместить папку на статическом хостинге с HTTPS (например, GitHub Pages). Серверное приложение не требуется: хостинг только отдаёт статические файлы.
2. Открыть ссылку в Chrome на Android.
3. Меню браузера → «Установить приложение» / «Добавить на главный экран».

Если не хочешь размещать файлы в интернете, можно открыть `index.html` локально, но установка PWA и офлайн-кэш могут не работать. Прямые API-запросы требуют интернета.

## Возможности
- Котировки избранных USDT-пар и изменение за 24 часа.
- Свечной график (15m, 1h, 4h, 1d, 1w).
- RSI(14), EMA20/EMA50, локальный диапазон.
- Fibonacci Retracement по диапазону последних 100 свечей.
- Ценовые алерты, настройки и избранные монеты сохраняются в localStorage.
- Кэш оболочки PWA для повторного открытия.

## Ограничения
- Данные свечей и котировок берутся из публичного Binance Spot API. Binance может быть недоступен в отдельных сетях/регионах; при сбое приложение покажет ошибку.
- Приложение не исполняет сделки и не подключается к аккаунту биржи.
- Алерты проверяются, пока страница активна. Мобильные ОС могут приостанавливать вкладки в фоне; гарантированных уведомлений 24/7 нет.
- Новости, Polymarket, деривативы, funding/OI/liquidations, Telegram и AI в этой сборке отсутствуют.
- Данные локальны для браузера и могут быть потеряны при очистке данных браузера.
- Это аналитический инструмент, не финансовая рекомендация.

## Приватность
Ключи API не используются. Запросы котировок отправляются напрямую на Binance. Личные настройки хранятся локально в браузере.
