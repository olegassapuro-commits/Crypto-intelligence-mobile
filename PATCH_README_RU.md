# Crypto Intelligence Paper Trading Patch v0.2.0

Этот патч добавляет в существующую мобильную PWA вкладку «Симулятор» (Paper Trading). Сервер и AI не требуются.

## Файлы для замены в корне GitHub-репозитория
- `index.html` — заменяет текущий файл, добавляет вкладку и интерфейс симулятора.
- `sw.js` — заменяет текущий файл, обновляет кэш PWA.

## Новые файлы
- `paper.js`
- `paper.css`

`app.js`, `style.css`, `manifest.webmanifest`, `icon.svg` заменять не нужно.

## Установка с телефона
1. Распакуйте архив.
2. В GitHub откройте репозиторий → Add file → Upload files.
3. Загрузите `index.html`, `sw.js`, `paper.js`, `paper.css` в корень репозитория.
4. Подтвердите Commit changes.
5. Дождитесь GitHub Pages deployment.
6. Откройте приложение, обновите страницу. Если старая версия из кэша — полностью закройте PWA/Chrome и откройте снова.

## Что есть
- Реальные публичные Spot котировки и свечи Binance.
- Виртуальные Spot Long и Futures Long/Short.
- Market и Limit заявки (лимитные заявки исполняются при достижении цены во время работы приложения).
- Плечо x1–x50 для Futures.
- SL/TP, ручное закрытие, открытые позиции, ожидающие заявки, журнал и экспорт CSV.
- Локальное хранение баланса и сделок в localStorage.
- График с линиями цены входа, SL и TP.

## Ограничения и точность
- Сделки полностью виртуальные; реальные ордера не отправляются.
- Данные берутся с публичного Binance API; доступность зависит от сети и региона.
- Комиссии условные: Spot 0,10% за сторону, Futures 0,05% за сторону. Это параметры модели, не персональные тарифы Binance.
- Funding оценивается по последней доступной ставке и времени удержания, а не по фактической истории начислений.
- Ликвидация — упрощённая оценка с maintenance margin 0,5%; реальная биржевая формула зависит от уровня позиции, риска и активов.
- Симулятор проверяет SL/TP и лимитные заявки по последней полученной цене. Если приложение закрыто или телефон отключён от сети, события не обрабатываются в фоне.
- Баланс и журнал хранятся только на этом устройстве/в браузере. Очистка данных сайта может удалить их. Перед очисткой экспортируйте CSV.
- Cross/Isolated не реализованы как точные биржевые режимы: в этой версии каждая Futures-позиция изолированно резервирует заданную маржу.
- Это учебный paper trader, не инструмент точного воспроизведения исполнения Binance.
